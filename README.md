# HPLeila — نسخه اختصاصی لیلا

اپلیکیشن فارسی مدیریت کالا، انبار، خرید، فروش، فاکتور و هزینه‌های فروشگاه هیرکان پلاست با هویت بصری اختصاصی لیلا.

**نسخه آزمایشی:** 1.9.0 (Android build 17)

## امکانات

- مدیریت کالاها، دسته‌بندی‌ها و موجودی انبار؛ حذف ایمن یا غیرفعال‌سازی کالاهای دارای سابقه و امکان فعال‌سازی مجدد
- ثبت خرید، فروش، برگشت و تعدیل موجودی
- داشبورد با فروش امروز و ماه، سود ناخالص/خالص ماه، هزینه‌ها و وضعیت موجودی
- **آمار و گزارش‌ها:** کل فروش و خرید، انتخاب سال و ماه شمسی، فروش ماهانه و سالانه، مقایسه با دوره قبل، نمودار فروش روزانه و ماهانه، تفکیک روزهای هفته، پرفروش‌ترین روز و روزهای بدون فروش؛ داشبورد نیز سود ناخالص/خالص، هزینه‌ها و وضعیت و ارزش انبار را نمایش می‌دهد
- فاکتور فروش چندقلمی با جست‌وجوی کالا، نام/تلفن مشتری اختیاری، تخفیف، مبلغ نهایی، PDF/چاپ/اشتراک‌گذاری و ثبت برگشت کامل فاکتور
- مشاهده تاریخچه و جزئیات فاکتورها و چاپ/اشتراک‌گذاری PDF
- نمایش مبالغ به ریال و معادل تومان در بخش‌های پشتیبانی‌شده
- ثبت و پیگیری هزینه‌های فروشگاه
- ورود اطلاعات عملیاتی از CSV
- تهیه و اشتراک‌گذاری نسخه پشتیبان JSON و بازیابی اطلاعات
- رابط فارسی و تاریخ شمسی؛ کارکرد آفلاین برای عملیات محلی
- لوگو و هویت بصری اختصاصی لیلا با گل طلایی و پس‌زمینه سبز یشمی

## گزارش‌ها چگونه محاسبه می‌شوند؟

گزارش‌ها از تراکنش‌های موجود در پایگاه داده همین فروشگاه خوانده می‌شوند و داده‌های فروشگاه را تغییر نمی‌دهند. مجموع خرید از تراکنش‌های «ورود» محاسبه می‌شود و فروش بر اساس تراکنش‌های «فروش» است. این گزارش‌ها جایگزین حسابداری رسمی یا محاسبه دقیق بهای تمام‌شده به روش FIFO نیستند. پس از نصب، اعداد بر اساس سوابق موجود نمایش داده می‌شوند؛ اگر سابقه‌ای ثبت نشده باشد، نمودار مربوطه خالی خواهد بود.

## نصب و اجرا برای توسعه‌دهندگان

نیازمند Flutter SDK سازگار با Dart درج‌شده در `pubspec.yaml` و اندروید ۸ یا بالاتر (API 26+) است.

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

ساخت APK:

```bash
flutter build apk --release --target-platform android-arm,android-arm64 --split-per-abi
```

فایل‌های خروجی در `build/app/outputs/flutter-apk/` قرار می‌گیرند.

## حفظ اطلاعات هنگام به‌روزرسانی

این نسخه برای **به‌روزرسانی برنامه نصب‌شده** در نظر گرفته شده است، نه نصب تازه. پیش از نصب هر نسخه آزمایشی:

1. از داخل برنامه یک نسخه پشتیبان JSON تهیه کنید و آن را خارج از گوشی/پوشه برنامه نیز نگه دارید.
2. برنامه را حذف نکنید؛ حذف برنامه ممکن است داده‌های محلی را پاک کند.
3. نصب به‌روزرسانی باید با همان شناسه بسته و امضای معتبر نسخه نصب‌شده انجام شود.
4. پس از نصب، تعداد کالاها، چند تراکنش قدیمی، هزینه‌ها و فاکتورها را بررسی کنید.

بازیابی فایل پشتیبان می‌تواند داده‌های فعلی را جایگزین کند؛ فقط زمانی بازیابی کنید که لازم است و پیش از آن از داده‌های فعلی هم پشتیبان جداگانه بگیرید.

## وضعیت انتشار

در نسخهٔ 1.9.0 قابلیت‌های هم‌تراز با آخرین نسخهٔ بررسی‌شدهٔ مغازه‌دار به HPLeila منتقل شده‌اند: نوع تراکنش پیش‌فرض «ورود» است و فروش از مسیر فاکتور انجام می‌شود؛ کالاهای دارای سابقه به‌جای حذف مخرب غیرفعال می‌شوند؛ برگشت کامل فاکتور ثبت می‌شود و در آمار فروش کسر می‌گردد. سود تقریبی با قیمت خرید فعلی محاسبه می‌شود، نه روش FIFO. این شاخه همچنان باید با build موفق و بررسی روی دستگاه تأیید شود. پیش از استفاده روزمره، باید ساخت APK، امضا، نصب روی نسخه موجود و حفظ اطلاعات واقعی روی دستگاه آزمایش شوند. این شاخه فقط مربوط به HPLeila است؛ برنامه مغازه‌دار تغییر نمی‌کند.
