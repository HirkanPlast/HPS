# HPLeila (HPS)

اپلیکیشن مدیریت انبار، فروش، خرید و هزینه‌های فروشگاه هیرکان پلاست.

**نسخه:** 1.5.2

## امکانات

- مدیریت کالاها و دسته‌بندی محصولات
- ثبت خرید، فروش، برگشت و تعدیل موجودی
- صدور فاکتور فروش چندقلمی، ثبت مشتری اختیاری، تخفیف و مبلغ نهایی
- مشاهده، چاپ و اشتراک‌گذاری فاکتور فروش به صورت PDF
- محاسبه و نمایش مبالغ به ریال و معادل تومان
- داشبورد فروش، سود و هزینه‌ها
- ثبت و پیگیری هزینه‌های فروشگاه
- وارد کردن اطلاعات عملیاتی از فایل CSV
- تهیه نسخه پشتیبان به صورت فایل JSON
- اشتراک‌گذاری فایل پشتیبان از طریق منوی اشتراک‌گذاری اندروید؛ برنامه‌هایی مانند تلگرام، واتساپ، ایمیل و سایر برنامه‌های سازگار، بسته به برنامه‌های نصب‌شده
- بازیابی اطلاعات از فایل پشتیبان JSON
- رابط فارسی و تاریخ شمسی
- قابلیت استفاده آفلاین؛ اشتراک‌گذاری فایل به برنامه مقصد و اتصال آن نیاز دارد

## پیش‌نیازها

- Flutter SDK سازگار با محدودیت نسخه Dart در pubspec.yaml
- اندروید ۸ یا بالاتر (API 26+)

## نصب و اجرا

```bash
flutter pub get
flutter run
```

## ساخت APK مخصوص گوشی‌های اندرویدی

```bash
flutter build apk --release --target-platform android-arm,android-arm64 --split-per-abi
```

برای Galaxy J4 از فایل `app-armeabi-v7a-release.apk` و برای Galaxy A34 و A52 معمولاً از فایل `app-arm64-v8a-release.apk` استفاده کنید. فایل‌های خروجی در `build/app/outputs/flutter-apk/` قرار می‌گیرند.

## تهیه و اشتراک‌گذاری نسخه پشتیبان

1. وارد بخش **تنظیمات** شوید.
2. گزینه **اشتراک‌گذاری نسخه پشتیبان** را انتخاب کنید.
3. از منوی اشتراک‌گذاری اندروید، برنامه مقصد را انتخاب کنید.

نسخه پشتیبان به شکل فایل JSON ساخته می‌شود. آن را در جای امن نگه دارید و پیش از بازیابی، مطمئن شوید فایل مربوط به داده‌های موردنظر شماست. بازیابی کامل می‌تواند داده‌های عملیاتی موجود را جایگزین کند؛ پیش از آن یک نسخه پشتیبان جداگانه تهیه کنید.

## وارد کردن اطلاعات

برای وارد کردن داده‌ها، از گزینه‌های ورود فایل در بخش **تنظیمات** استفاده کنید و قالب CSV مورد انتظار برنامه را رعایت کنید. پیش از وارد کردن اطلاعات اصلی، از داده‌های فعلی نسخه پشتیبان تهیه کنید.
