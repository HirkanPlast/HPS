# HPLeila (HPS)

اپلیکیشن مدیریت انبار، فروش، خرید و هزینه‌های فروشگاه هیرکان پلاست، با هویت بصری اختصاصی HPLeila.

**نسخه:** 1.6.5 (build 14)

## امکانات

- مدیریت کالاها و دسته‌بندی محصولات
- ثبت خرید، فروش، برگشت و تعدیل موجودی
- صدور فاکتور فروش چندقلمی، ثبت مشتری اختیاری، تخفیف و مبلغ نهایی
- مشاهده، چاپ و اشتراک‌گذاری فاکتور فروش به صورت PDF
- محاسبه و نمایش مبالغ به ریال و معادل تومان
- داشبورد فروش، سود و هزینه‌ها
- ثبت و پیگیری هزینه‌های فروشگاه
- وارد کردن اطلاعات عملیاتی از فایل CSV
- تهیه نسخه پشتیبان به صورت فایل JSON
- اشتراک‌گذاری فایل پشتیبان از طریق منوی اشتراک‌گذاری اندروید
- بازیابی اطلاعات از فایل پشتیبان JSON؛ انتخاب فایل بدون فیلتر محدودکننده، بررسی ساختار JSON پیش از بازیابی و جلوگیری از شروع بازیابی برای فایل نامعتبر
- رابط فارسی و تاریخ شمسی
- قابلیت استفاده آفلاین
- هویت بصری اختصاصی Leila با گل طلایی و پس‌زمینه سبز یشمی درون برنامه و آیکون صفحه اصلی اندروید

## پیش‌نیازها

- Flutter SDK سازگار با محدودیت نسخه Dart در pubspec.yaml
- اندروید ۸ یا بالاتر (API 26+)

## نصب و اجرا

```bash
flutter pub get
flutter run
```

## ساخت APK مخصوص گوشی‌های اندرویدی

```bash
flutter build apk --release --target-platform android-arm,android-arm64 --split-per-abi
```

برای Galaxy J4 از فایل `app-armeabi-v7a-release.apk` و برای Galaxy A34 و A52 معمولاً از فایل `app-arm64-v8a-release.apk` استفاده کنید. فایل‌های خروجی در `build/app/outputs/flutter-apk/` قرار می‌گیرند.

## تهیه و بازیابی نسخه پشتیبان

پیش از نصب نسخه جدید، برای اطمینان از سلامت اطلاعات فروشگاه، یک نسخه پشتیبان JSON تهیه کنید. فایل را در جای امن نگه دارید. بازیابی موفق، داده‌های عملیاتی موجود را جایگزین می‌کند؛ فایل انتخاب‌شده پیش از شروع بازیابی بررسی می‌شود و فایل نامعتبر نباید باعث جایگزینی اطلاعات فعلی شود. همیشه پیش از بازیابی، از اطلاعات فعلی نسخه پشتیبان جداگانه بگیرید.
