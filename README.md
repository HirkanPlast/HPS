# فروشگاه هیرکان پلاست (HPS)

سیستم مدیریت انبار، فروش و هزینه‌های فروشگاه هیرکان پلاست

**نسخه:** 1.0.1

## ویژگی‌ها

- ثبت تراکنش‌های ورود، فروش، برگشت و تعدیل
- محاسبه خودکار موجودی با وضعیت رنگی (تأمین / کمبود / بدون موجودی)
- مدیریت هزینه‌های جانبی فروشگاه
- داشبورد «در یک نگاه» با فروش، سود ناخالص و سود خالص
- بک‌آپ روزانه خودکار به تلگرام
- دو نقش: فروشنده (دسترسی کامل) و مدیر (تنظیمات + بازیابی)
- کاملاً آفلاین (فقط برای بک‌آپ به اینترنت نیاز دارد)
- رایگان و متن‌باز

## پیش‌نیازها

- Flutter SDK 3.2 یا بالاتر
- اندروید ۸ به بالا (API 26+)

## نصب و اجرا

```bash
git clone <آدرس-ریپو>
cd hps
flutter pub get
flutter run
```

برای ساخت APK:

```bash
flutter build apk --release
```

فایل خروجی در مسیر زیر قرار می‌گیرد:
`build/app/outputs/flutter-apk/app-release.apk`

## راه‌اندازی بک‌آپ تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید و یک ربات بسازید.
2. توکن ربات را کپی کنید.
3. یک گروه یا چت خصوصی بسازید و ربات را به آن اضافه کنید.
4. برای گرفتن Chat ID می‌توانید از ربات‌های آماده مثل `@userinfobot` استفاده کنید یا پیام بدهید و از API بگیرید.
5. در اپ → تنظیمات → توکن و Chat ID را وارد و ذخیره کنید.
6. دکمه «تست ارسال» را بزنید.

بک‌آپ روزانه به صورت خودکار (تقریباً هر ۲۴ ساعت) ارسال می‌شود. می‌توانید دستی هم بک‌آپ بگیرید.

## ساختار پروژه

```
lib/
├── main.dart
├── app.dart
├── models/          # Product, Transaction, Expense
├── database/        # SQLite helper
├── screens/         # تمام صفحات
├── services/        # Telegram + Backup
└── utils/           # ثابت‌ها و تاریخ شمسی
```

## نکات مهم

- محصولات دو واحدی (-K و -D) به صورت دو کالای جداگانه تعریف شده‌اند.
- هنگام فروش اگر موجودی کافی نباشد فقط هشدار داده می‌شود (جلوگیری نمی‌کند).
- سود خالص = فروش ماه − بهای تمام‌شده تقریبی − هزینه‌های ماه
- برای بازیابی بک‌آپ در نسخه‌های بعدی امکان import از فایل اضافه خواهد شد.

## مجوز

این پروژه برای استفاده داخلی فروشگاه هیرکان پلاست ساخته شده است.

## وارد کردن کالاهای اولیه

پس از نصب اپ:
1. به **تنظیمات** بروید.
2. گزینه **وارد کردن ۷۰ کالای اولیه** را بزنید.
3. تمام محصولات فایل اکسل اصلی وارد می‌شوند.

## بازیابی بک‌آپ از فایل

1. فایل JSON بک‌آپ را (که از تلگرام دانلود کرده‌اید) روی گوشی ذخیره کنید.
2. در تنظیمات → **بازیابی کامل از فایل JSON** را بزنید.
3. فایل را انتخاب کنید. تمام داده‌ها جایگزین می‌شوند.
