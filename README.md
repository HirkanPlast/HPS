# HPLeila (HPS)

اپلیکیشن مدیریت انبار، فروش، خرید و هزینه‌های فروشگاه هیرکان پلاست.

**نسخه:** 1.5.1

## امکانات
- مدیریت کالاها و دسته‌بندی محصولات
- ثبت خرید، فروش، برگشت و تعدیل موجودی
- محاسبه و نمایش مبالغ به ریال و معادل تومان
- داشبورد فروش، سود و هزینه‌ها
- ثبت و پیگیری هزینه‌های فروشگاه
- وارد کردن اطلاعات عملیاتی از فایل CSV
- تهیه و بازیابی نسخه پشتیبان JSON
- اشتراک‌گذاری نسخه پشتیبان از طریق منوی اشتراک‌گذاری اندروید
- رابط فارسی و تاریخ شمسی
- قابلیت استفاده آفلاین

## پیش‌نیازها
- Flutter SDK سازگار با محدودیت نسخه Dart در pubspec.yaml
- اندروید ۸ یا بالاتر (API 26+)

## نصب و اجرا
```bash
flutter pub get
flutter run
```

## ساخت APK کم‌حجم
برای ساخت APKهای جداگانه و کوچک‌تر برای معماری‌های مختلف پردازنده:
```bash
flutter build apk --release --split-per-abi
```
خروجی‌ها در `build/app/outputs/flutter-apk/` قرار می‌گیرند. فایل `app-arm64-v8a-release.apk` برای بیشتر گوشی‌های اندرویدی جدید مناسب است؛ برای سازگاری گسترده‌تر می‌توان از نسخه‌های دیگر متناسب با دستگاه استفاده کرد.

## نسخه پشتیبان
در بخش **تنظیمات**، گزینه اشتراک‌گذاری نسخه پشتیبان را انتخاب کنید و برنامه مقصد را از منوی اندروید برگزینید. پیش از بازیابی فایل JSON، از داده‌های فعلی نسخه پشتیبان جداگانه تهیه کنید؛ بازیابی ممکن است داده‌های عملیاتی را جایگزین کند.

## وارد کردن اطلاعات
در بخش **تنظیمات** از گزینه‌های ورود فایل استفاده کنید و قالب CSV مورد انتظار برنامه را رعایت کنید. پیش از وارد کردن اطلاعات اصلی، نسخه پشتیبان تهیه کنید.

این پروژه برای مدیریت داخلی فروشگاه هیرکان پلاست توسعه داده شده است.
